Krate Cloud

Apps people have published. Every one is a single file that runs in a sandbox: it tells you what it wants — the network, a folder, the microphone — before it starts, and it gets nothing you have not agreed to.

How to open one

Install Krate, then copy an app's command and paste it into your terminal. Krate downloads the app, shows you what it is asking for, and opens it once you agree.

How to make your own

Type krate in a terminal. It asks what you want to make, writes it with an AI you already have, and hands you the file. Then publish it and it appears here.
