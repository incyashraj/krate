What people made

Apps people have published. Each one is a single file that runs on your own computer in a sandbox — it tells you what it wants before it starts, and gets nothing else.

Open one

Install Krate once, then click any app here and copy its command. Krate downloads it, shows what it asks for, and opens it when you agree.

Make your own

Type krate in a terminal. It asks what you want to make, and an AI you already have writes it.

Publish it

krate publish yourapp.krate, or drop the file on the publish page. It appears here with your name on it.
