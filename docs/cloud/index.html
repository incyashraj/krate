Apps that show what they want.

Every app here is one file. Install Krate once, open any of them, and you see exactly what it is asking for before a line of it runs.

Nothing is described by hand

Each listing is read out of the file: its name, its size, its identity, and every permission it asks for. Nobody gets to describe their own app more kindly than it behaves.

You can check what you got

Every app carries an identity computed from its contents. Run krate run app.krate --dump-caps and compare it to the one shown here.

It runs on your computer

Downloading is the only thing that happens here. The app opens locally, with exactly the access you allow, online or off.

Opening your app

It just downloaded to your computer. Here is how to run it.

1

Install Krate once

Krate is the small runtime that opens any .krate app. Paste this into a terminal:

curl -fsSL https://krate.tech/install.sh | sh
2

Double-click the file

Find the .krate file in your Downloads and double-click it. Krate shows you exactly what the app wants to access, then opens it.
