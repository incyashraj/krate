Someone sent you an app.

It is one file, ending in .krate. Here is how to open it, and what you will see first.

  1. 1

    Get Krate

    Krate is the thing that opens these files. You install it once, and it works for every app anyone sends you after that.

    I have a Mac I have Windows I have Linux
  2. 2

    Double-click the file

    Find the file you were sent and double-click it, the same as you would a document or a photo.

  3. 3

    Read what it wants, then decide

    Before anything runs, a window tells you what the app is asking for — in plain words, with the reason for each. Nothing happens until you say yes, and the app only ever gets what you left ticked.

On a Mac

Download Krate.app from the latest release and unzip it. Pick the aarch64 file if your Mac is from 2020 or later, and x86_64 if it is older.

The first time only: right-click Krate.app and choose Open. macOS warns about apps it has not seen before, and right-click then Open is how you get past that warning. After that, double-clicking any .krate file just works.

On Windows

Open PowerShell — press the Start button, type PowerShell, and press Enter — then paste this line and press Enter:

irm https://krate.tech/install.ps1 | iex

That is the whole install. It does not need an administrator password.

On Linux

Open a terminal, paste this line, and press Enter:

curl -fsSL https://krate.tech/install.sh | sh

Then open the file you were sent by double-clicking it, or by typing krate run followed by the file name.

Common worries

Is this safe to open? Krate shows you what the app wants before it runs, and gives it nothing else. An app that asks to save a list cannot read the rest of your computer, even if it wanted to.

Do I need an account? No. There is nothing to sign up for.

Where does my data go? Nowhere. The app runs on your own computer, and anything it saves stays there.

What if I say no? The app does not start. It cannot run halfway with less than it asked for.
