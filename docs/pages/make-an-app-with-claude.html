Make an app with Claude

Ask Claude for an app in plain words and get back a link that opens it in any modern browser, phones included, with nothing to install. Claude writes the app. Krate builds it, checks it and publishes it to your Krate account.

Add the connector

Connect Krate to Claude once.

Krate is a connector for Claude: a remote MCP server at one address. You add it on claude.ai, and from then on Claude can make Krate apps for you in any chat.

  1. Open your connectors

    On claude.ai, go to Customize > Connectors. Choose Add, then Add custom connector.

  2. Paste Krate's address

    Name it Krate and paste this as the server URL. Click Continue, choose Sign in when needed, then click Add.

    https://hub.krate.tech/mcp

  3. Sign in to Krate

    Sign in with GitHub, Google or an email link, and choose Allow. The page says exactly what the connector may do: build apps you ask for and publish them to your account. Claude asks for this when you connect, or the first time it builds.

On Claude's Free plan you can add one custom connector. On a Team or Enterprise plan, an Owner adds Krate under Organization settings > Connectors, and each member then connects with their own Krate sign-in.

Ask for an app

Say what you want, in plain words.

Start a chat and ask. Say what the app is for and what it should show first. For example:

Using the Krate connector, make me a simple habit tracker app that works on my phone and my laptop, and give me the link.

If Claude does not reach for Krate on its own, turn the connector on for that chat from the + menu, or name it in your request as the example does.

Use Krate every time

Have Claude use Krate every time.

Add one line to Claude's instructions, so you don't have to name Krate in every chat. On claude.ai, click your initials in the lower left, choose Settings, then Your Claude, and paste this line under Instructions:

When I ask for an app, build it with the Krate connector so it runs on every device.

In the older settings layout the place is Account, under Instructions for Claude. These instructions apply to all your chats; Anthropic's help page has the details.

What happens

Claude writes it. Krate builds and checks it.

  1. Claude reads Krate's guide

    The connector hands Claude Krate's reference for writing an app: the files an app is made of, the API it may use, the permissions it may ask for, and worked examples.

  2. Claude writes the app

    It writes the app's code and its manifest, the list of what the app is allowed to touch, and sends the files to Krate.

  3. Krate compiles and checks it

    Krate builds the code, confirms it uses only Krate's API, and runs it once. If something fails, Claude gets Krate's own words on what went wrong and how to fix it, fixes it and builds again. A build usually takes one to five minutes.

  4. You get the link

    An app that passes is published to your Krate account, and Claude gives you its link.

Krate runs no AI of its own here. The AI is Claude, on your Claude plan. Krate never sees your conversation, only the app files Claude sends it. What Krate keeps.

Open it and share it

One link, every screen.

The link Claude gives you opens the app in any modern browser, phones included, with nothing to install and no account. Open it on your phone and your laptop, or send it to anyone in a chat or an email.

Claude also gives you the app's own link. With the Krate runtime installed, that link opens the same app natively on macOS, Windows and Linux, as a real window.

The app is unlisted on your account: only people with the link can open it. Before it opens, anyone running it sees what it asks for. An app starts with no access to files or the network, and reaches only what the person allows.

Want it different? Ask Claude for the change, and it builds the app again.

In Claude Code

Using Claude Code? Add the plugin.

The Krate plugin for Claude Code adds the same connector, and a skill that builds on your own machine: Claude reads Krate's API, starts from a working template, checks every change with krate check-app, and packs the app as one .krate file. It needs Krate installed.

claude plugin marketplace add incyashraj/krate-claude-plugin
claude plugin install krate@krate

Only want the connector? Add it on its own:

claude mcp add --transport http krate https://hub.krate.tech/mcp

The connector speaks the open Model Context Protocol over streamable HTTP with OAuth sign-in, so other AI tools that support remote MCP servers can use the same address.

Questions

Questions.

Do I need to know how to code?

No. You describe the app and Claude writes the code. Krate checks it before you ever see a link.

Do the people I send it to need Claude or Krate?

No. The link opens in their browser with nothing to install and no account. Installing the Krate runtime is only for running apps natively on a computer.

Do I need a Krate account?

To build, yes: you sign in once, with GitHub, Google or an email link, and the apps Claude builds are published to that account. Claude can search the public Krate gallery for you without a sign-in.

How many apps can I build?

Each Krate account can start up to 10 builds an hour and 30 a day through the connector. When Claude fixes an app and builds it again, that is a new build.

What does Krate keep, and how do I disconnect?

The privacy page lists what the connector sends Krate, what Krate keeps and for how long, and how to take its access back. To stop using it, remove Krate from Customize > Connectors in Claude.

Ask Claude for an app.

Add the Krate connector once, then ask in plain words. You get a link that opens the app in any browser, phones included, and the same app runs natively on Mac, Windows and Linux.
