Access control

Know what an app wants before it opens.

A Krate app does not quietly inherit access to your computer. It declares what it needs, explains why, and waits for your decision.

  • Allow only the folders and capabilities you are comfortable with.
  • Withhold required access and the app does not start.
  • Inspect the open source runtime if you want to verify the enforcement.
Krate limits what an app can access. It does not promise that every app is free of bugs.

Help center

Plain answers before you start.

If something is still unclear, ask us directly on GitHub.

What is a .krate file?

It is an application file containing the app and a manifest that lists the access it requests. The Krate runtime opens and runs it.

Do I need to be a developer?

No. If someone sends you a Krate app, install the runtime once and open the file. The creator tools are separate.

Does Krate guarantee every app is safe?

No. Krate limits the app to the capabilities you approve. It does not guarantee that an app has no bugs or that every approved action is sensible.

Where does the app run?

It runs locally on your Mac, Windows, or Linux computer. The planned Krate cloud will help people store, discover, update, and share app files.

Can an AI agent create a Krate app?

Yes. Coding agents can plug into the authoring step. Krate then builds, checks, packages, and verifies the resulting app.
