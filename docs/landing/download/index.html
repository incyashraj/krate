For developers

Command line

The krate tool on its own, for developers and scripts. Or in a terminal:

On Mac and Linux
curl -fsSL https://krate.tech/install.sh | sh
On Windows
irm https://krate.tech/install.ps1 | iex
  • macOS, Apple Silicon
  • macOS, Intel
  • Windows, x64
  • Windows, ARM
  • Linux, x86_64
  • Linux, arm64
  • Checksums (SHA256SUMS)
