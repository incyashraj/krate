Questions

Direct answers about Krate.

These came from people seeing Krate for the first time. The short answer is first, with the technical boundary underneath.

03 / PortableHow can the same .krate file open on Mac, Windows, and Linux?

The app does not call AppKit, Win32, or Linux APIs directly. It calls Krate interfaces described with WIT. The Krate host on each operating system translates approved calls into local behavior.

The .krate file carries the WebAssembly component and its requested access. It is one portable app artifact, not three native installers hidden in one download.

10 / NameDoes the name collide with a Rust “crate”?

Rust calls a package a crate, so the similarity is real. Krate uses a different spelling and refers to the portable container that carries an application and its requested access.

We will keep making the distinction explicit wherever Rust developers could reasonably confuse the two.

02 / WebWhy not use an HTML file, browser link, or Electron?

A browser link is the right answer when an app fits inside the browser. Krate is for local software that needs files, desktop behavior, or other host features that a web page cannot use cleanly.

An Electron app ships a browser engine and still needs platform packaging. A Krate app is a WebAssembly component. It does not bundle a browser per app, and the shared runtime controls its access to the computer.

05 / AccessCan an app hide what it accesses or ignore the permission screen?

The permission list is not only a label written by the app. Krate checks supported host operations at the runtime boundary. If the app tries an operation that was not granted, the call is denied before the host adapter performs it.

If a required permission is denied, the current app flow refuses to start and explains what is missing.

06 / SecurityIs Krate ready for any untrusted app from the internet?

Not yet. The capability boundary is working and useful, but v0.1.2 is a first release and the project is not claiming production hardening against hostile third-party code today.

Use the published examples or apps you are testing yourself. The current limits and threat model are public.

07 / RuntimeWhy does the person receiving an app need the Krate runtime?

The runtime is the stable layer that makes one app file portable and enforces its access. Without it, every app would need to bring a separate engine and separate operating-system code.

You install Krate once. After that, each .krate file can use the same host, permission model, and opening flow.
