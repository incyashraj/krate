QUESTIONS

Direct answers about Krate.

These came from people seeing Krate for the first time. The short answer is first, with the technical boundary underneath.

01How can the same .krate file open on Mac, Windows, and Linux?

The app does not call AppKit, Win32, or Linux APIs directly. It calls Krate interfaces described with WIT. The Krate player on each operating system translates approved calls into local behavior.

The .krate file carries the WebAssembly component and its requested access. It is one portable app, not three native installers hidden in one download.

02Why not use an HTML file, browser link, or Electron?

A browser link is the right answer when an app fits inside the browser. Krate is for local software: it works offline, it works next year even if the sender disappears, and “it cannot use the network” is enforced on your machine rather than promised in a policy.

An Electron app ships a browser engine and still needs platform packaging. A Krate app is a WebAssembly component. It does not bundle a browser per app, and the shared player controls its access to the computer.

03Can an app hide what it accesses or ignore the permission screen?

The permission list is not only a label written by the app. Krate checks supported host operations at the boundary. If the app tries an operation that was not granted, the call is denied before it reaches the operating system.

If a required permission is denied, the app refuses to start and explains what is missing.

04Is Krate ready for any untrusted app from the internet?

Not yet. The capability boundary is working and useful, but Krate is young and we are not claiming production hardening against hostile third-party code today.

Open apps from people you know, or from the gallery. The current limits and threat model are public.

05Why does the person receiving an app need Krate?

Krate is the player: the stable layer that makes one app file portable and enforces its access -- like a media player for movies. Without it, every app would have to bring its own engine and its own operating-system code, and the small-file story would die.

They install Krate once, about 24 MB. After that, every .krate anyone sends them just opens, through the same permission flow.

06Does the name collide with a Rust "crate"?

Rust calls a package a crate, so the similarity is real. Krate uses a different spelling and refers to the portable container that carries an application and its requested access.

We will keep making the distinction explicit wherever Rust developers could reasonably confuse the two.
