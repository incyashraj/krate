About

About Krate.

Krate turns a sentence into a real desktop app: one small file that opens on Mac, Windows and Linux, and asks before it touches anything.

What Krate is

An app made with Krate is a single .krate file, usually tens of kilobytes. Inside is the app compiled to WebAssembly, the permissions it asks for, and the Rust source it was built from. The Krate player opens the same file on every desktop, gives it a window and nothing else, and asks the person before the app may use files, the network or the camera.

Krate Studio

Studio is where apps are made: describe one, and an AI writes it, builds it, opens it and fixes what it sees. It runs on your own computer with the AI you already use, or in your browser at krate.tech/app.

Open source

The runtime, the player and the command line are open source under MIT or Apache-2.0, developed in public at github.com/incyashraj/krate. Every measurement Krate publishes names the evidence it came from.
