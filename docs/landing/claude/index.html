Claude Desktop

Ask Claude for an app. It opens on your computer.

Add Krate to Claude Desktop once. Then every app you ask Claude for is built on your computer and opens in its own window, with its own name and icon.

Add to Claude Desktop for Mac For Windows

Free. One file for Claude Desktop on a Mac or a Windows PC.

1

Open the file

Double-click krate-mac.mcpb, or drag it onto Claude Desktop.

2

Click Install

Claude Desktop shows Krate with an Install button. That is the whole setup: no terminal and no settings.

3

Ask for an app

Claude writes it, Krate builds and checks it on your computer, and it opens.

“Make me a habit tracker with a weekly grid.”

Yours, on your computer

Every app Krate makes is a real program you keep.

Its own window

The app opens right away with its own name and icon. Ask Claude to keep it and it goes in your Applications folder or Start menu.

One file to send

Each app is a single small .krate file in your Krate Apps folder. Send it to anyone and it opens with Krate on their computer.

You say what it may do

An app gets a window and nothing else until you allow more. The first time it opens, Krate asks you, and only you can say yes.

Good to know

Is there anything else to download?

Once. The first app you make sets up Krate's builder, the compiler apps are built with: about 127 MB on a Mac with Apple silicon, 141 MB on an Intel Mac, 226 MB on Windows. Claude tells you while it happens. It goes in Krate's own folder and changes no other software on your computer.

What does it need?

Claude Desktop on macOS or Windows. Krate itself is inside the file you install.

Using Claude in a browser?

Add Krate's connector there instead, and apps open from a link in any browser, phones included: Make an app with Claude.

Make your first app

Add Krate to Claude Desktop, then just ask.
