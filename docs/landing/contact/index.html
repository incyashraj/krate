Reporting an app on Krate Cloud is different: every listing has a report link that opens an issue naming that app, so it does not get lost among everything else.

Before reporting a bug, krate doctor checks your setup and prints what it finds. Including that output saves a round trip. If it is a security problem, please open a private advisory on the security tab rather than a public issue.
