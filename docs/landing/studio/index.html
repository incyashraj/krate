FROM IDEA TO A REAL APP

One place to make it, change it and send it.

01

Ask for the app

No starter project and no framework choice. Describe the useful thing you need. Your AI writes the app while Studio shows what is happening.

02

The file carries its source. Ask for a change tomorrow and the AI edits the app you already have instead of starting again.

The receiver sees what the app wants before it runs. Krate gives it only that access, then opens the same file on all three desktop systems.

What to expect

  • The studio installs the Krate runtime with it. There is nothing else to set up.
  • You need an AI it can drive. Claude, Codex, Gemini and Copilot all work, and the studio can install one for you.
  • Signed and notarised by Apple, so it opens like any other app -- drag it to Applications and double-click. No warnings to click through.
  • The terminal tool stays exactly as it is. The studio is an addition, not a replacement.
