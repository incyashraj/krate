What to expect

  • The studio installs the Krate runtime with it -- there is nothing else to set up.
  • You need an AI it can drive. Claude, Codex, Gemini and Copilot all work, and the studio can install one for you.
  • macOS builds are not notarised yet, so the first open needs right-click then Open.
  • The terminal tool stays exactly as it is. The studio is an addition, not a replacement.
