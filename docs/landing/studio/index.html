What to expect

  • The studio installs the Krate runtime with it. There is nothing else to set up.
  • You need an AI it can drive. Claude, Codex, Gemini and Copilot all work, and the studio can install one for you.
  • The studio is not signed by Apple yet, so macOS blocks the first open and says it "could not verify" it. Open System Settings → Privacy & Security, scroll to the bottom, and press Open Anyway. (Right-click → Open no longer works on current macOS -- that dialog only offers Done or Move to Bin.)
  • The terminal tool stays exactly as it is. The studio is an addition, not a replacement.
