Share an app made with AI as one link

Describe your app in Krate Studio, then send it as a link: it opens in any modern browser, phones included, with nothing to install and no account. On Mac, Windows and Linux the same .krate file also runs natively, and every app shows what it asks for before it opens.

Already have a .krate file? Jump to sending it. Made a website or a script with another AI tool? krate port (beta) and the porting guide bring it over.

Make it by describing it

Open Krate Studio on Mac, Windows or Linux, or in your browser, and say what you want in plain words. The AI builds the app, checks it and packs it into one .krate. Then keep changing it by asking: a new button, a dark mode, a CSV export.

Desktop Studio works with Claude, Codex, Grok or Gemini. In the browser, Krate's own AI makes your first app. You do not need to know Rust; the AI writes it.

Developers can do the same from the command line with their own AI agent:

krate doctor
krate ai
krate create "a regex tester with a pattern box and live matches" --agent claude --output regex.krate

krate create --help lists every option.

Test before you send it

Studio checks every build and opens the app for you to try. Click through it, resize the window, type a bad input. From the command line, see what it asks for and run it:

krate run regex.krate --dump-caps
krate run regex.krate --prompt

The first command shows the permission request without running anything. The second opens the app after you review it.

Send it as a link or a file

As a link. Publish the app and you get a link like https://hub.krate.tech/run/<id>. Paste it into a chat or an email; it opens in any modern browser, phones included, with nothing to install and no account. Publishing needs a Krate account; opening never does.

krate publish regex.krate

As a file. Once you have tried the app, send the .krate itself by email, chat or a shared drive. One file, from 37 KB. On Mac, Windows and Linux, the Krate runtime opens it natively; here is what the person receiving it does. They never need your AI account, your source or a Rust toolchain.

What the person you send it to sees

Before the app opens, they see exactly what it asks for and decide. It starts with no access to their files or the network, hosts it did not declare stay unreachable, and it keeps its data in storage of its own. See how permissions work and how one file opens on every screen.

Questions

Can I change the app after I send it?

Yes. Ask for the change, then send the new version. Studio keeps each version, so you can go back if a change goes wrong.

Does the person I send it to need my AI tool or an account?

No. A link opens in their browser with nothing to install and no account. You need a Krate account only to publish a link; opening one never needs one.

Which AI tools can make a .krate?

Krate Studio on your computer works with Claude, Codex, Grok or Gemini. In the browser, Krate's own AI makes your first app.

Do I need to know how to code?

No. You describe the app in plain words and the AI writes the Rust, checks it and packs it. Developers can still open the source and change it by hand.

Can I send it by email or chat?

Yes. A link or a .krate goes anywhere a picture goes: an email, a chat, a shared drive.

What if my app needs the internet?

It declares each host it talks to, and the person opening it sees that list and approves it before the app runs. Hosts it did not declare stay unreachable.
