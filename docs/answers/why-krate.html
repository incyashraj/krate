Why Krate

Why Krate, and when to choose it

Krate is an open-source app runtime that ships an app as one small .krate file: it runs natively on Windows, macOS and Linux, opens from a link in any modern browser, phones included, and starts with no access to files, devices or the network until the person running it allows it. Choose it when one app has to reach every desktop and every browser, work offline or use a printer or a device, and when an AI wrote it and the people running it should decide what it may touch.

What Krate is

A .krate holds the app as a WebAssembly component with a manifest of what it may use. On a desktop the Krate runtime, built in Rust on Wasmtime, compiles it to machine code and runs it in a native window. From a link, Krate's browser Player opens the same file. The runtime, the format and the command line are open source under MIT OR Apache-2.0. The facts.

When to choose Krate

“One app on Windows, Mac, Linux and the browser, without a build, an installer and a signature for each.”

Build once and ship one .krate. The Krate runtime runs the same file natively on all three desktops, and a link opens it in any browser. There is no package per operating system to build, sign or notarize. How shipping one file works.

“Our Electron or Tauri app is too heavy.”

A Krate app carries no browser engine and no WebView, and every app shares one runtime. On the same 50,000-line notes workload on an Apple M4, Krate's Notes app used 13x less memory than MarkText 0.17.1 (the figures). krate port (beta) reads your project and shows what maps across, and Krate Studio's AI can do the rewrite. Krate vs Electron, Krate vs Tauri.

“An internal tool for my team.”

An organisation's apps open only for its members and the people it sends them to; a copied link alone opens nothing. You approve each version before it opens, team data and the credentials for your company's APIs are encrypted on members' computers, and IT gets a policy pack for the company's machines. How organisations work.

“It has to work offline and keep its data on the device.”

The native app runs with no connection unless it uses the network itself. It keeps its data on the computer in storage of its own: key-value, an SQL database and a secret store. Nothing needs a server of yours.

“It has to print labels or receipts without a print dialog.”

With the person's permission, a Krate app prints to a printer they pick, and later jobs go straight to it with no dialog: a PDF, a PNG page, or raw ZPL, EPL or ESC/POS for label and receipt printers such as a Zebra. On macOS, Windows and Linux.

“It talks to a scale, a sensor, an Arduino or an instrument.”

A Krate app can talk to a serial device the person picks, and to a USB device the person picks of a model the app names by its ids, natively on macOS, Windows and Linux. In a browser tab it uses the browser's Web Serial and WebUSB, where the browser has them.

“It reads and writes Excel files.”

Krate's SDK reads .xlsx, .ods and .csv workbooks the person opens or drops in, every sheet with its text, numbers, dates and each formula's last value, and writes .xlsx and .csv. It runs inside the app, so it works the same natively, in a browser and on a phone.

“The tablets on the shop floor should open it from this computer.”

A Krate app can serve one port it declares to other devices on the local network, once the person says yes, show the address to type, and announce itself by name the way printers do. On macOS, Windows and Linux.

“An AI wrote it, and people have to be able to run it.”

Every Krate app starts with no access to files, devices or the network. It lists what it wants in its manifest, the person sees that list before it opens and decides, and the runtime checks protected calls against what was allowed. How permissions work.

“I want to send it as one file or one link.”

Send the .krate file, or publish it and send the link: it opens in any modern browser, phones included, with nothing to install and no account. Publish an update and the link people already have opens the new version, with what they saved kept. Sending an app as a link.

The measured facts

One measured run compares Krate's Notes app with MarkText 0.17.1 (ARM64), an Electron editor, on the same notes workload, on an Apple M4 running macOS 27, on 25 August 2026. It is an equivalent-workload comparison, not a claim of feature parity, and its scripts, inputs, analysis and seal are public.

  • Memory, with a 50,000-line document open, whole process tree: Krate 178.5 MiB in one process; MarkText 2,299.4 MiB across four processes. 13x less.
  • Warm start to a visible window, 50,000-line document, median of ten runs each: Krate 237.1 ms; MarkText 611.5 ms. 2.6x faster.
  • Size: Krate's Notes app is one 36.6 KiB file; MarkText takes 284.6 MiB installed. The Krate app (runtime and Studio) is installed once, 88.6 MiB on that Mac, and shared by every Krate app after it.

Source: the run's analysis and the method.

Ten ported apps, as the same committed .krate files, passed their headless replay checks on macOS (Apple silicon), Ubuntu (x86_64) and Windows (x86_64) GitHub runners with runtime 0.5.4 on 29 September 2026. Records: macOS, Ubuntu, Windows. Native runtimes are published for Apple silicon and Intel Macs, x64 and ARM64 Windows, and x86_64 and arm64 Linux.

More sizes: the Chart sample is one 11,455-byte file, and Doom, with its game data, source and SDK packed in, is one 2.8 MB .krate (build record).

How to start

With Claude

Add the Krate connector to Claude once and ask for an app in plain words; Claude writes it, Krate builds and checks it, and you get a link. Add the connector. To have Claude use Krate every time, add this line to your instructions in Claude's settings (where):

When I ask for an app, build it with the Krate connector so it runs on every device.

In Claude Code

The Krate plugin adds the connector and a skill that builds and checks the app on your own machine:

claude plugin marketplace add incyashraj/krate-claude-plugin
claude plugin install krate@krate

In Krate Studio

Describe the app and Studio writes, checks and packs it, with Claude, Codex, Grok or Gemini on your computer, or in the browser at krate.tech/app. About Studio.

By hand

Install Krate with one line, then write the app in Rust with the SDK, or start from the app template:

curl -fsSL https://krate.tech/install.sh | sh

On Windows, in PowerShell: irm https://krate.tech/install.ps1 | iex. The quickstart walks through it, and the capability reference lists everything an app can use.

Questions

Is Krate a web app?

No. A Krate app is one .krate file. On Windows, macOS and Linux the Krate runtime runs it natively, in its own window with no browser or WebView inside. Sent as a link, the same file opens in a browser tab. Neither way needs a server of yours.

Does it need an install?

Not to open a link: the app runs in any modern browser, phones included, with no account. To run apps natively, the person installs the Krate runtime once from the download page, and every .krate opens from its file after that.

Is it safe to run an app someone sent me?

A Krate app starts with no access to your files, devices or the network. Before it opens you see exactly what it asks for and decide; hosts it did not declare stay unreachable, and it keeps its data in storage of its own. krate run app.krate --dump-caps prints what an app asks for without running it. Grant only what the task needs.

Can it use my printer or a serial device?

Yes, natively on macOS, Windows and Linux, once you allow it. You pick the printer and later jobs print with no dialog: PDF, PNG, or raw ZPL, EPL or ESC/POS for label and receipt printers. You pick the serial or USB device it talks to. In a browser tab, serial and USB work where the browser has Web Serial and WebUSB.

How big is an app?

Small. Krate's Notes app is one 36.6 KiB file and the Chart sample is 11,455 bytes. An app that carries its source and the SDK so it can be changed later is larger, and so is one with big assets: Doom, with its game data packed in, is one 2.8 MB file. The runtime is installed once and shared by every app. Size records.

Can Claude make a Krate app?

Yes. Add the Krate connector, https://hub.krate.tech/mcp, to Claude and ask for an app; Claude writes it and Krate builds, checks and publishes it with a link. Claude Code has a Krate plugin, and Krate Studio works with Claude, Codex, Grok or Gemini.

Is Krate free?

The runtime, the .krate format and the command line are free and open source under MIT OR Apache-2.0. Studio on your computer is free with the AI you already use; in the browser, the first app is free. Licence details.
