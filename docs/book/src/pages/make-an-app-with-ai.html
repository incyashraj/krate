Krate make an app by asking
A guide anyone can follow

Ask for an app. Get one file back. Share it.

You describe the small app you want in one sentence. Krate has an AI write it, and hands you a single file. You send that file to someone. They double-click it, see exactly what it is allowed to touch, say yes, and use it. That is the whole idea.

What this actually is

Software you can pass around like a document

Today, getting a small custom tool usually means finding a developer, waiting, and installing something you have to trust. Krate changes the shape of that. You ask for what you want in plain words. The result is one file — like a PDF, but it is a real, working app.

The important part: before that app runs on anyone's computer, it has to show a list of what it wants access to, and the person decides. An app that only needs its own little folder can never quietly reach the rest of your machine. If someone declines what it needs, it simply does not open — it never runs half-way.

No coding needed to use this. If you can type a sentence and send a file, you can do everything on this page. The one setup step (installing the krate tool) is a copy-paste, and we show it below.
The three moving parts
1. You ask “Make a checklist app that saves my items.” One sentence, plain words.
2. You get a file A single .krate file — the finished app, checked and packaged for you.
3. Anyone opens it They double-click it, review what it can access, allow it, and use it. Same file works on Mac, Windows, and Linux.
One-time setup

Get the krate tool once

You only do this once, on the computer where you will make apps. A developer friend can do this part for you if you would rather not touch a terminal — after that, making apps is a single command.

# download and build the tool (needs Rust, from rustup.rs) git clone https://github.com/incyashraj/krate cd krate cargo build --release -p krate-cli # the tool is now at target/release/krate — put it on your PATH
The tool carries everything it needs inside it. Once you have krate, you do not need the download again to make apps.
Make an app

One command turns your sentence into a shareable file

1

Type what you want

Open a terminal and run the command below, changing the sentence in quotes to describe your app. This example makes a checklist that saves its items.

krate create "Make a checklist app that saves my items" \ --output checklist.krate
2

Krate does the rest

It writes the app, builds it, checks it can only touch what it says it will, packages it, and proves it works before the file even exists. You end up with checklist.krate.

Created checklist.krate requested access: - a window - read and write its own "checklist" folder Send checklist.krate to someone; they can double-click it to open it.
3

Send the file

checklist.krate is one ordinary file. Email it, message it, drop it in a shared folder — however you normally send a file. The person receiving it does not need to trust you or read any code.

Prefer to have a real AI model write it, rather than the built-in template? Add --author-cmd "<your agent command>" and the model writes the app; Krate still checks and proves it the same way. Details are in the developer guide.
Open it — what the other person does

Double-click, review, and use it

1

Double-click the file

Before anything runs, a window appears listing exactly what the app is asking for. Here: a window, and read/write to its own checklist folder — nothing else on the machine is reachable.

2

Review and allow

You can read the whole list of what it wants. If it looks right, allow it and the app opens. If it ever asks for more than it should, that is your cue to say no.

3

Use it like any app

Type a new item into the box and press Enter or click Add item. Click a checkbox to mark something done.

4

Close it and open it again

Everything you did was saved as you went. Open the file again and your list is exactly as you left it — checked items checked, new items still there.

Try saying no. Open it once more and decline the folder access. The app does not start at all. It never opens half-working — the check happens before its code runs. That wall is the whole point.
Why this is safe to share

An app can only touch what you allow

Normally, running someone's app means trusting it with your whole computer. Krate flips that. Every app has to declare what it needs, that list is shown to you before it runs, and it can never reach beyond what you approve. A note app gets its notes folder. A checklist gets its checklist folder. Neither can read the rest of your machine or reach the internet unless it asked and you agreed.

And because the app was checked and its permission wall proven at the moment it was made, a broken or overreaching app never becomes a file you could send in the first place.
