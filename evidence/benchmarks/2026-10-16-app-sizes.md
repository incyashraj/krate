# App sizes quoted in the README, 2026-10-16

Two sizes the README states, each measured from a named build. Sizes only:
no speed is claimed from these runs.

## Doom: the packed `.krate`

Built from `apps/krate-doom` at 80a34d375 with the shareware `doom1.wad`
v1.9 (md5 `f0cefca49926d00903cf57551d901abe`, 4,196,020 bytes) built in,
on an Apple M4 Mac, packed and run with the published Krate 0.5.4 CLI.

```
$ DOOM_WAD=.../doom1.wad cargo component build --release
    Creating component target/wasm32-wasip1/release/krate_doom.wasm
$ stat -f %z target/wasm32-wasip1/release/krate_doom.wasm
4662401
$ krate pack target/wasm32-wasip1/release/krate_doom.wasm --manifest manifest.toml -o Doom.krate
wrote Doom.krate (2758035 bytes)
$ krate run Doom.krate --headless --auto-grant -- quick
I_InitGraphics: DOOM screen size: w x h: 320 x 200
ticks:300 frames:342 seconds:7.0 fps:48.9
```

2,758,035 bytes is 2.8 MB. The file carries the game, the WAD, and the
app's own source and SDK so it can be rebuilt. It declares three
permissions: `ui.window:create`, `io.stdout`, `io.args`.
